# Advanced commands

Everyday builds and phone transfers are in the project root: `build & install via USB.bat`,
`build & install via WiFi.bat`, and `build & install via Bluetooth.bat`.

This folder contains build-only, install-only, pairing, verification and diagnostic
commands. Signed builds and release preparation are under `release/`.

See [the command guide](../README.md) for arguments and setup instructions.
